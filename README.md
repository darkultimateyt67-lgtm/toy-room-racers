# Toy Room Racers

**▶ Play it in your browser: https://darkultimateyt67-lgtm.github.io/toy-room-racers/**

Toy cars racing around a giant bedroom. Race on orange toy track under the bed, beneath the desk, over bridges and off book jumps, climb from Rookie to Master, and upgrade every part of your car.

## Features

- **10 detailed cars** — Sand Buggy, Ice Cream Van, Muscle Coupe, Monster Truck, Police Cruiser, Rally Hatch, Formula Toy, Hot Rod, Hyper Wedge and Rocket Car, each with curved bodywork, working suspension, visible moving engine parts, glass with an interior, and its own synthesised engine sound.
- **5 upgradeable parts per car** — engine, battery, tyres, nitro and bumper, plus paint colours.
- **6 tiers (D, C, B, A, S, M)** — each with its own 3 tracks (18 in total) and its own track colours. Win 2 races in a tier to unlock the next one and its cars.
- **Hills, jumps, bridges and figure-of-eights**, racing against 3 AI drivers.
- **Coin Rush** — free-roam the whole room against the clock.
- **Modern graphics** — soft contact shadows, bloom, physically based materials, with Auto / Ultra / High / Medium / Low quality settings.

## Controls

| Key | Action |
|---|---|
| W / ↑ | Throttle (hold on the start line to rev) |
| S / ↓ | Brake / reverse |
| A D / ← → | Steer |
| Shift | Nitro |
| Space | Handbrake drift |
| R | Reset car |
| C | Change camera |
| M | Mute |
| Esc | Pause |

## Running it yourself

Open `index.html` in Chrome or Edge. An internet connection is needed the first time, because the 3D engine (three.js) loads from a CDN.
